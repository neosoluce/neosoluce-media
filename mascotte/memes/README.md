# Memes animés (format « POV » TikTok/Instagram)
Dépose ici un clip court généré par IA (Google Flow, Kling, OpenArt…) : `nom.mp4`
et, à côté, un fichier `nom.txt` contenant UNE ligne : le texte du meme (ex. « Pov : moi et ma PS5 à partir du 19 novembre »).
Sans .txt, l'agent choisit le texte dans mascotte/IDEES-MEMES.md (même nom).
L'agent Vidéo fait le montage (tools/make_meme_reel.py) et programme la publication.
