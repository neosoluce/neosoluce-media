# Images officielles de GTA VI (publiées par Rockstar Games)

**USAGE INTERDIT actuellement** : ces fichiers sont conservés mais ne doivent être utilisés nulle part (site, réseaux,
Reels, stories, épingles) tant que Noah n'a pas confirmé explicitement par écrit une licence Take-Two (demande en

Rockstar met en ligne ses images officielles de GTA VI ici : https://www.rockstargames.com/VI/media
(captures, illustrations, fonds d'écran). Leur règlement dit que Rockstar/Take-Two « ne s'oppose pas »
à l'usage de ses contenus par les fans **sans but commercial**.

## Comment remplir ce dossier (5 minutes, une seule fois, puis à chaque nouvelle image officielle)
1. Sur ton téléphone ou ton ordinateur, ouvre https://www.rockstargames.com/VI/media
2. Ouvre « Screenshots » (captures) et « Artwork & Wallpapers » (illustrations).
3. Télécharge les images (sur téléphone : appui long > Enregistrer l'image).
4. Ouvre https://github.com/neosoluce/neosoluce-media/tree/main/officiel > « Add file » > « Upload files »,
   sélectionne les images (jusqu'à 100 par envoi), puis « Commit changes ».
5. Garde le nom d'origine ou renomme simplement : `vice-city-plage.jpg`, `lucia-jason-moto.jpg`…

Uniquement des images téléchargées sur le site officiel de Rockstar. Jamais d'image qui a fuité, ni d'image
prise sur un autre site, une autre page ou chez un autre créateur.

## Vidéos officielles
Les clips officiels (portraits animés des personnages, jaquette animée) vont dans `officiel/videos/`.
GitHub refuse sur le site web les fichiers de plus de 25 Mo : dans ce cas, envoie simplement le fichier
(ou un .zip) dans la conversation avec Claude, qui l'ajoute au dépôt.
Pas de trailer ni d'extrait de trailer : on les partage seulement avec le lien YouTube officiel.
