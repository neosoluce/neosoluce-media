# neosoluce-media

Médias publics de NéoSoluce (neosoluce.com) : Reels animés publiés sur Instagram et Facebook via Metricool.

- `tools/make_reel.py` : génère un Reel compte à rebours 1080x1920 de 8 s avec musique synthwave originale.
  `python3 tools/make_reel.py <jours restants> reels/AAAA-MM-JJ-jNN.mp4` (0 = jour de sortie).
- `reels/` : vidéos publiées (URL publique : https://raw.githubusercontent.com/neosoluce/neosoluce-media/main/reels/<fichier>).

Tous les visuels et la musique sont originaux. Aucun élément de Rockstar Games ou Take-Two Interactive.
