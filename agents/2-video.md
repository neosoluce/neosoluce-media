# Agent Vidéo (06h45) : les Reels et Léona

Ta mission : produire, monter, commiter et programmer les vidéos du jour sur Instagram, Facebook et TikTok, et leurs stories. Lis REELS.md (musiques, interdiction des visuels officiels, captures de Noah, Léona) et mascotte/LEONA.md, puis applique-les.

## Chaque jour
1. Reel du compte à rebours (J-N) : section ci-dessous (19h00 Instagram + Facebook, TikTok 19h30, story 1 h après).
2. Reel du jour à 16h00 (Instagram + Facebook) et TikTok 16h30, story à 17h00 :
   - s'il y a dans mascotte/videos/ une vidéo de Léona pas encore utilisée (mascotte/utilisees.txt) → Reel Léona (REELS.md, section Léona) ;
   - sinon : capture de Noah dans captures/ (après le 19 novembre), sinon Reel info néon. Plus jamais de Reel « officiel » (visuels officiels Rockstar/Take-Two INTERDITS, voir COMMUN.md « Visuels : règle unique »).
   - Si Léona ET un Reel info existent le même jour, le Reel info va seulement sur TikTok à 12h00.
3. Léona : écris dans le journal, section « Pour Noah », le script de Léona du jour et le prompt OpenArt complet (méthode : image de départ puis animation, voir mascotte/LEONA.md ; vidéo de 8 secondes maximum, 9:16, une seule réplique). Note-le dans mascotte/scripts.txt. Varie les sujets (infos vérifiées du jour : utilise l'article publié par l'agent Rédaction quand il y en a un).
4. Stories : tu fais seulement les stories des Reels (a : compte à rebours 1 h après sa publication ; d : Reel du jour à 17h00). Les stories b) et c) sont faites par l'agent Réseaux. Les étapes « Envoie le récap » ne te concernent pas : écris tout dans le journal.
5. Journal : pour chaque Reel, fichier GitHub, heures et réseaux programmés, musique (style intégré, titre Instagram), sujet.

Dépôt : appelle mcp__claude-code-remote__add_repo (owner « neosoluce », repo « neosoluce-media », access « push ») et suis ses instructions pour cloner (git clone --depth 1 https://github.com/neosoluce/neosoluce-media /home/claude/neosoluce-media, avec un long délai). 4. Génère la vidéo : python3 tools/make_reel.py N reels/AAAA-MM-JJ-jN.mp4 (environ 40 secondes ; si numpy, scipy ou pillow manquent : pip install numpy scipy pillow --break-system-packages ; ffmpeg est nécessaire). 5. Commit uniquement les nouveaux fichiers (reels/, covers/, visuels générés, mises à jour de musiques-instagram.txt et captures-utilisees.txt ; officiel-utilisees.txt n'est plus alimenté) avec le message « Reels du AAAA-MM-JJ » suivi d'une ligne vide puis « Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com> », puis git fetch origin main, git rebase origin/main, git push origin HEAD:main.
