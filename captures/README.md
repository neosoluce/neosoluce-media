# Captures de jeu de Noah (GTA VI)

Dépose ici tes propres captures vidéo de GTA VI, filmées sur TA console (PS5 : bouton Créer).

Comment faire depuis le téléphone :
1. Sur la PS5 : bouton Créer > enregistrer un clip de 15 à 60 s (1080p suffit).
2. Envoie-le sur ton téléphone avec l'appli PlayStation (Bibliothèque de captures > Télécharger).
3. Ouvre https://github.com/neosoluce/neosoluce-media/tree/main/captures dans le navigateur,
   touche « Add file » > « Upload files », choisis la vidéo (25 Mo max : coupe-la si besoin), puis « Commit changes ».
4. Nomme le fichier avec un mot-clé : `AAAA-MM-JJ-sujet.mp4` (ex. `2026-11-20-vol-voiture.mp4`).
   Tu peux ajouter un fichier texte du même nom (`.txt`) avec une phrase sur ce qu'on voit.

Règles (Rockstar autorise les captures des joueurs à condition de ne pas gagner d'argent directement avec,
de ne pas spoiler l'histoire et de ne jamais publier de vidéo qui a fuité) :
- uniquement TES captures, jamais un trailer, une vidéo de Rockstar ou d'un autre créateur ;
- pas de scène qui révèle l'histoire (cinématiques, fin, rebondissements) ;
- le son du jeu est coupé automatiquement (les radios du jeu sont protégées).
